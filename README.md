* Prototipo de Grúa *

Este proyecto es un prototipo básico de una grúa STS (Ship-to-Shore) que demuestra una funcionalidad básica. La idea es simular la maniobra o movimiento de un contenedor por medio de un gancho o "Spreader" que se mueve con una cabina.

El proyecto incluye una grúa hecha con figuras 3D primitivas. La grúa funciona con dos scripts, uno para la cabina (movimiento horizontal), y otro para el spreader (movimiento vertical). Contiene un HUD con ciertos datos, y física simulada (gravedad con RigidBodies, y movimiento del viento).
